# MindSpace

🚧 **BUILD STATUS: IN PROGRESS**

MindSpace is a real-time collaborative whiteboard where people can create or join rooms, share ideas, draw diagrams, and brainstorm together. Powered by Socket.IO, it aims to make collaboration seamless with live synchronization and persistent whiteboards that can be saved and reopened using a unique key.

**Currently under development, with a focus on building a seamless real-time collaboration experience.**
